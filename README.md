# MikroTik Firewall Rules

RouterOS firewall filter rules for IPv4 and IPv6.

## Contents

- `mikrotik ipv4 firewall filter rules` — IPv4 filter rules
- `mikrotik ipv6 firewall filter rules` — IPv6 filter rules

## Usage

Open a terminal on your MikroTik device (Winbox, WebFig, or SSH) and paste the rules, or import them with `/import`. Review each rule and adjust interface names, address lists, and subnets to match your network before applying.

> **Note:** Apply firewall changes with care — a bad rule can lock you out. Use Safe Mode in Winbox when testing.
